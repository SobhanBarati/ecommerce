# 🛍️ E-Commerce Fashion Store

A modern, full-stack e-commerce platform for fashion products.

## 🚀 Tech Stack

### Frontend
- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- TanStack Query + Zustand

### Backend
- Node.js + Express
- TypeScript
- MongoDB + Mongoose
- JWT Authentication

### Tooling
- pnpm (monorepo)
- ESLint + Prettier
- Conventional Commits
